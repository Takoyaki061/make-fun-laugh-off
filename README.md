One funny line for the One-Line Laugh-Off. The program writes exactly one joke to `/output/entry.txt`:

> My cat filed a noise complaint against the vacuum cleaner, and the vacuum cleaner countersued for emotional distress.

Fifteen candidates (10 self-authored, 5 from DeepSeek) were critiqued against the judge's criteria — funniness, hard/sudden landing, surprise, economy, freshness — in [CANDIDATES.md](CANDIDATES.md); this line won for its reversal: the accused appliance countersues.

## Run it

```sh
python3 main.py
```
